# 🫀 Прогнозирование сердечно-сосудистых заболеваний: EDA и ML-пайплайн

Аналитический проект по исследованию медицинских данных и построению модели классификации для прогнозирования риска сердечных заболеваний. Проект демонстрирует полный цикл работы с данными: от предобработки и визуализации до обучения модели и автоматизированной генерации отчёта.

## 🎯 Цель проекта

Разработать воспроизводимый аналитический пайплайн, который выявляет ключевые факторы риска и предсказывает наличие заболевания с интерпретируемыми метриками качества.

## 🛠 Использованные инструменты и навыки

- **Язык**: R
- **Анализ и визуализация**: `tidyverse`, `ggplot2`, `corrplot`
- **Машинное обучение**: `xgboost`, `caret`, `pROC` (5-кратная кросс-валидация, early stopping)
- **Автоматизация отчётности**: `rmarkdown`, `knitr`
- **Ключевые навыки**: Исследовательский анализ данных (EDA), обработка категориальных признаков, оценка метрик классификации (Accuracy, Precision, Recall, F1, ROC-AUC), интерпретация важности признаков (Feature Importance)

## 📊 Ключевые результаты

- **Датасет**: 918 наблюдений, 12 признаков (физиологические показатели пациентов)
- **Лучшая модель**: XGBoost с оптимальными гиперпараметрами (`eta=0.05`, `max_depth=4`, `subsample=0.8`)
- **Главные предикторы**: 
  - Наклон сегмента ST (`ST_Slope`)
  - Максимальный пульс (`MaxHR`, r ≈ -0.43 с целевой переменной)
  - Уровень холестерина (`Cholesterol`)
  - Индекс ST-депрессии (`Oldpeak`, r ≈ 0.43)

Результаты согласуются с клинической практикой и подтверждают прогностическую ценность модели.
